Project Handoff helps your agent leave a small, useful record, check what still holds, and resume with one safe next action. Settled decisions keep their reasons. Unknowns stay visible.

It works with the project files you already have. No Memory install, account, database or background process.

Install from the public source

git clone https://github.com/michaeljabbour/amplifier-skill-project-handoff.git
cd amplifier-skill-project-handoff
python3 scripts/install.py --dest ~/.agents/skills

Use Git and Python 3.11+. Choose the skills directory your agent reads; ~/.agents/skills is one supported convention, not a universal setting. Existing conflicting copies are refused. The ZIP below is the alternative.

A prompt to start with
Use Project Handoff to resume this project from its existing records. Tell me what still holds, what is uncertain, and the next safe action. Do not change files or start the next task.
