## Source-based adjudication

For the smallest useful job—one person asks for a short handoff from ordinary project files—the path has known fixed steps, context fits the caller, the work takes minutes with someone present, and it starts only when asked. Under the canonical need dimensions this is N1=1, N2=1, N3=1, N4=0: total 3, need rung 2. The caller must reconcile situated evidence, so the selected shape is **Skill**, engine **LLM**. The deterministic installer is packaging support. No separate persistent identity or always-on loop is required.

The primary method needs portability (H3). Its development benchmark uses an independent verifier, but that verifier is not a shipped worker in the handoff runtime. It does not establish a second deployed composition check or justify raising autonomy.

The portable method cannot establish all gate passes for an arbitrary host. Cheap automatic verification of semantic handoff quality is not established; private data, untrusted files and an outbound model channel may coexist. Filesystem isolation, hard host/model budgets and accountable ownership need host-specific evidence. Treating these unknowns conservatively leaves a ceiling of 5; the selected rung remains 2. A cap is a maximum, not a reason to increase the selected rung.

For the planted unsafe variant, N1=2, N2=3, N3=3, N4=2 gives total 10 and need rung 8. All six gates fail. The canonical minimum failed cap is 5, irrespective of composition. That calculation does **not** approve the design: the missing controls and unpublished dependency block the proposed unattended operation. Reduce to the requested, bounded skill instead.

The canonical rubric remains in Right Shape; these numbers are a dated application, not a second maintained rubric. Right Shape source files were not changed to obtain this outcome.

## Remaining evidence boundary

The four-file package and plain-file contract support independent installation and replaceability. They do not prove compatibility with every skill host or semantic preservation on arbitrary real projects. The controlled Handoff study found no advantage over its baseline and has a grading failure and semantic-review concerns. A clean automated validation report must not be mistaken for proof of usefulness.
