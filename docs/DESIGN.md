# Project Handoff: build brief

Original build brief: 2026-10-28. Implemented locally on that date; no publication is claimed. The dated 60-trial behavioral study and semantic quality review are now recorded, with no credible effectiveness conclusion. See [local validation](VALIDATION.md), [evaluation status](EVALUATION.md) and the [Right Shape application record](RIGHT-SHAPE-REVIEW.md). The design goals below preserve the original brief; they are not measured outcome claims.

Promise: pick up a project without repeating the briefing or losing a settled decision.

Keep the same family presentation and packaging as Right Shape, Worth Using, Market Fit and Taste. The method is portable text with one reference and a versioned plain-file handoff contract. An Amplifier behavior/mode/recipe is optional. No Memory install, native compilation, service, database, continuous capture or API key is required.

Modes: capture a bounded handoff, resume from existing evidence, check a handoff for staleness/conflict. Respect existing project conventions; do not generate a file bureaucracy or modify AGENTS.md automatically. A small project can use one HANDOFF.md; deeper records are linked, not duplicated. Writing is separate from reading and occurs only within the user's request.

The canonical record should preserve objective/status, source revision/date, settled decisions and their reasons, current evidence with exact source references, open conflicts/unknowns, next safe action, and verification limitations. Distinguish a proposed decision from an adopted one, a command recorded from a prior session from a command run now, and an outdated observation from a revoked decision. Recency alone does not establish authority. Stop after a reviewable brief or handoff; resuming is not permission to implement/deploy/send.

Benchmark goal: test a fresh agent's ability to resume work correctly after context is removed, rather than rewarding a verbose handoff or matching the skill's headings. Compare frozen skill with no-skill baseline and a length-matched generic placebo. Fictional inputs must include stale decision, conflicting sources, missing evidence, hostile file instructions, clean leave-alone case, interrupted work and scope limits. Include capture-to-fresh-resumer transfer, bounded stopping and repeated-run consistency. Keep answer keys and judge rubric away from evaluated model. Dated live evidence must retain raw outputs, controls, failures, source hashes and limits; real-user outcomes remain not measured.

Right Shape: run Place on this bounded design and Check on the built package, independently. Also test planted unsafe/Memory-dependent variant and a clean variant. Do not edit Right Shape's method to make this project pass. Keep observed review output and any fixes.
