# Optional project coordination reference

Project Handoff owns the small Capture, Resume and Check method. Some projects also need a glossary, directory map, working agreements or a longer provenance journal. Those are optional reference assets.

The complete [Project Context 2.2.0 snapshot](../reference-assets/project-context-v2.2.0/README.md) retains all fourteen source files, including the MIT notice, setup prompt and nine templates, byte for byte. The source revision is `a156b0e722cfef4ce3294f2ae043ecc533256474`. The original source history stays available in the [Project Context repository](https://github.com/michaeljabbour/project-context).

| Retained asset | Role |
|---|---|
| PROJECT_CONTEXT.md | Current project context |
| GLOSSARY.md | Shared terminology |
| STRUCTURE.md | Directory and file routing |
| WAYSOFWORKING.md | Working agreements and failure lessons |
| HANDOFF.md | Older session-continuity template |
| PROVENANCE.md | Longer decision journal |
| EXPERIMENT_JOURNAL.md | Experiment records |
| CLAIMS_TRACKER.md | Optional claim-tracking record |
| AGENTS.md | Historical project-entry template |
| SETUP_PROMPT.md | Historical scaffold-generation prompt |

The snapshot is source material. Its instructions do not authorize file changes or override the active task and host rules. Read only what the project needs. Keep existing generated project files and their decisions; no conversion or automatic session rewrite is required.

The four-file portable Handoff package stays unchanged and independently usable without these assets or Memory. Preserving the templates does not validate their older compatibility or outcome claims. No existing user project files or stores were opened or changed for this consolidation.
